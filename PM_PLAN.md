# PM_PLAN — BigAmbitionStratMod

In-game advisor for one Big Ambitions save, then a new-game guide and autopilot. Version scheme `MAJOR.EPIC.COUNTER`. Current public version **1.19.1.1**. The first ship of a new epic phase is `1.N.1`. When an epic runs after a higher-numbered epic, **EPIC** is `max(shipped_epic) + 1` (Epic 9 after 1.13.x → 1.14.1). Never go backwards.

## Context

The game is Mono, build **3682**. A mod builds with `dotnet build` against `Big Ambitions_Data\Managed` (`BigAmbitions.dll`, `BigAmbitions.ModAPI.dll`). The pin is `doc/requirements/game-build.md`. Python save tools live in `script/`. The mod, when it exists, lives in `src/`. Evidence for the ledger is `doc/gemini/cache/ledger.log`. The mod writes `%LocalAppData%\ChaoticCEO\ceo.log`. The compile counter is gitignored `build_number.txt`. The mod informational version is `1.16.6.1+N`. The draw reference is `UnityEngine.IMGUIModule`.

Epic 1 closed on 17 businesses and 5865 statement rows. `ba:businesstype_liquorstore` is **food**. Do not relabel it inside a routes story. A warehouse story may add a specialty override only with a new test.

The end goal is a brand-new game played with no hands on the keyboard. Crossing **WinNetWorth** ($100M) logs `win.reached` once, and the autopilot keeps running. **SimHorizonDays** (365) is only the Epic 8 scoring window. The mod acts through game-state and command calls. It does not walk, drive, or hand-cart. The rules and the four stages are in [doc/requirements/strategy.md](doc/requirements/strategy.md). Calls not yet found are listed under *Unverified* in `doc/requirements/game-api.md`, and code does not use them.

Run order: Epics 12, 13, 9, and 8 are done. Epic 10 stays open. Epic **14** is the live-reading rulebook and runs its code stories before the Epic 10 story that needs them. **7.9–7.12** stay. **7.13** is **14.6**. **7.9** blocks **14.10**. Epic numbers stay as they are; the public **EPIC** segment is the phase counter. Epic 14 ships as `1.17`.

One story per branch. Human check after **2.2**, after **3.3**, and on every story in Epics 5 through 13. Each epic in the run order waits until the one before it works. Monte Carlo is only **8.4–8.5**. The story test gate reuses the save index. Rebuild it when the dropzone `.hsg` changes, when `script/Slice-SaveGame.py` changes, or at epic close.

A story that says overlay, panel, button, or in game names what appears on screen. Its human check is that screen or action. `mod.loaded` does not pass it. Dropping the on-screen part takes an explicit OK and an edit here. From Epic 7 on, a story is done in game when F9 shows it, or when the save changes. A headless story has to say so. "The running game does not call X" is not an exit.
